# LeanTail roadmap

1. **Prepare:** prove plugin loads, manually invokes, uninstalls; do structural check.
2. **Pilot:** three public fixture tasks, two replicates per mode (18 total agent runs), measure feasibility, refine prompts before preregistering final protocol.
3. **Main benchmark:** 12 tasks, five replicates each, same model and reset worktrees (180 runs).
4. **Public preview:** publish source, security limitations and preliminary evidence; invite focused feedback.
5. **Next release only if justified:** improve instructions from failures and rerun held-out tasks; maintain backward compatibility where possible.

**Out of scope for v0.x:** dashboard, telemetry, browser extension, agent command execution framework, hooks, persistent cross-project logs, installer executable.
